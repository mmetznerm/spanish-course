UPLOAD PARA O GITHUB

1. Extraia o ZIP no seu computador.
2. Abra o repositório https://github.com/mmetznerm/spanish-course
3. Clique em Add file > Upload files.
4. Envie os arquivos e a pasta data que estão dentro desta pasta extraída (não envie apenas o ZIP).
5. Confirme que a estrutura fica assim na raiz do repositório:
   index.html
   app.js
   styles.css
   README.md
   data/phrases.js
   data/survival-phrases.js
6. Clique em Commit changes.

Se o GitHub Pages já está habilitado para a branch main e a raiz do repositório, o site será atualizado após o commit.
